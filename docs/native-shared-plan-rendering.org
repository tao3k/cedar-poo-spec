* Proof-bound native encoding and the observed regression

=EncodedJson= separates lazy semantic JSON and certified native rendering.
Canonical object order/duplicate ownership and public value projections remain;
=compact_wire= preserves complete bytes. The source catalog builds certified
metadata rather than retaining a complete intermediate semantic catalog.

The first native leaf encoder compressed each key/value independently and joined
many small fragments. Source review found a separate official compression work
queue per scalar, while Lean's object compressor can share one queue. This is
an avoidable algorithm/representation cost, not a reason to add another cache.

Bounded row metadata now uses one official Lean =Json.compress= work queue per
object instead of a fresh queue for every field. The existing native constructor
binds the complete row value and wire. Bounded semantic leaf objects remain;
the complete catalog is still fragmented. No custom trusted serializer or parser
axiom was introduced. Compositional encoding certificates are not a new kernel
proof of Lean's JSON parser implementation.

Previous same-body controls observed about 35.953 MiB with JSON versus 3.531 MiB
without it. These are sampled resident observations, not live heap bytes. The

Retired objects need not uncommit arena pages. Existing core globals, remaining
40 raw model/data globals, retained ancestor metadata and semantic leaf values
have different lifetimes. No exclusive heap-byte decomposition or leak-freedom
claim is made. Earlier allocator receipts from the unqualified stale diagnostic
image are kept separately and do not characterize the final code.

The new observer reads existing Darwin public process fields in its bounded
thread: resident/virtual bytes, raw CPU counters, faults, page-ins and thread
state. Raw CPU units are not silently interpreted as nanoseconds. The public

zero/unavailable identity is explicit. Linux does not fabricate Darwin fields.
All 32 external observer unit tests pass without changing the sampling or
cleanup limits.
