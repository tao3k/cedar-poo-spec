Each case directory has source and limitation notes. The VLA command case
studies a published attack; the mission case projects a published
runtime-assurance result onto the same kind of untrusted high-level
command interface. The TARA case indexes the mission policy's treatment
matrix without replacing risk ratings. Uptane remains a separate
software-supply-chain example.
