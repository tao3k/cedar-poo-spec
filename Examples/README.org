* Overview

These examples exercise Cedar's upstream Lean specification through
Lean-POO composition and, where applicable, compare exported policies with
the official Cedar Rust authorizer. Each case README states its sources,
modeling assumptions, Lean claims, and runtime boundary.

Examples define readable policy models, revision flows, and exportable Cedar
scenarios. Exact regressions, invalid inputs, and scale checks belong in
[[file:../Tests/README.org][Tests]]; timing probes belong in
[[file:../Benchmarks/README.org][Benchmarks]]. The example modules do not
depend on either verification directory.

| Area | Cases |
|------+-------|
| [[file:Enterprise/README.org][Enterprise]] | Procurement, payment, agents, and vehicle command and mission authorization. |
| [[file:Health/README.org][Health]] | Clinical emergency access and wearable triage. |
| [[file:Governance/README.org][Governance]] | Data access, networks, countries, and ticket sharing. |
| [[file:Language/README.org][Language]] | Cedar syntax and extension coverage. |
| [[file:Scenarios/README.org][Scenarios]] | POO edit patterns and cross-case navigation. |

The focused checks and export commands are in the root =Justfile=.
