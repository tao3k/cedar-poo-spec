* Banking tool ownership

[[file:BankingToolOwner.lean][BankingToolOwner]] owns one Cedar permit slot for a banking line of
business and its selected Gateway actions. =introduce=, =revise=, and
=withdraw= expose the slot's Lean-POO edits. The
[[file:../../../Examples/Enterprise/AWS/FinancialServices/MultiAccountBanking/README.org][multi-account banking example]] uses separate Retail, Transaction, and
Lending objects; its incident revision narrows only Transaction's actions.
The published tool names, customer identities, cross-account credentials,
and data-plane checks remain with the example or a consuming application.

* Controller payment release

[[file:ControllerRelease.lean][ControllerRelease]] owns a controller permit slot. Its broad grant can
be strengthened in place with a matched-payment requirement and either a
decimal amount threshold or senior-controller membership. The
[[file:../../../Examples/Enterprise/Payment/README.org][payment release example]] composes this owner with independent duties,
risk, and legacy-retirement branches. The application chooses the decimal
threshold and authenticates payment attributes, actor membership, and the
effectful transfer.

* Insurance claims summary

[[file:ClaimSummaryVeto.lean][ClaimSummaryVeto]] owns one forbid slot for a claims-summary action when
the principal satisfies a supplied policyholder condition. The
[[file:../../../Examples/Enterprise/AWS/FinancialServices/LakehouseGateway/README.org][insurance lakehouse example]] supplies its AgentCore Gateway action and
Cognito group projection, then composes the insurance rule with independent
Lakehouse location controls. The public object neither assumes Cognito nor
imports an AWS module.

* Boundary

=Vertical/FinancialServices/= holds finance-specific reusable controls.
=Platform/AWS/= holds AWS AgentCore projection helpers; finance controls
do not import that platform adapter. =Data/Lakehouse/= holds the general
location boundary. A downstream AWS financial-services profile selects all
three layers. Scenario records, source quotations, policy artifacts, and
complete workflows remain in =Examples/=.
